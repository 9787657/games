# 蔚蓝航线 · AZURE RUN

一款使用原生 **WebGL 2** 编写的 3D 帆船竞速游戏。玩家需要调整帆角、借助风势，依次穿过 6 道浮标并返回海风港，以最短时间完成整段航线。

项目不依赖第三方运行时或图形库。海面、天空、岛屿、帆船、浮标、航迹与界面效果均由代码实时生成，启动后无需联网即可游玩。

## 游戏特色

- 原生 WebGL 2 实时渲染，无第三方运行时依赖
- Gerstner 风格动态海浪、波光与程序化天空
- 可随波浪起伏、倾斜的 3D 帆船与动态帆面
- 受风向、船身朝向和帆面角度影响的航行速度
- 程序化岛屿、植被、灯塔、浮标和航迹泡沫
- 实时竞速计时、最佳成绩记录、浮标引导与小地图
- 近景 / 远景追逐镜头、程序化海浪与风声
- 支持键盘和触屏操作

## 快速开始

### 环境要求

- Node.js（建议 18 或更高版本）
- 支持 WebGL 2.0 的现代浏览器，例如最新版 Chrome、Edge 或 Firefox

项目没有 npm 依赖，无需执行 `npm install`。

### 启动游戏

```powershell
npm start
```

然后在浏览器中打开：

```text
http://127.0.0.1:4173
```

如需使用其他端口，可以通过 `PORT` 环境变量指定：

```powershell
$env:PORT=8080
npm start
```

> 请通过本地服务器访问项目，不要直接双击 `index.html`。浏览器通常会限制 `file://` 页面加载 ES Module。

## 玩法

1. 点击“开始航行”，等待 3 秒倒计时结束。
2. 观察 HUD 中的风向、风速、航行效率和目标方向。
3. 调整帆面，让帆船保持较高的推进效率。
4. 按顺序穿过 6 道浮标，注意避开岛屿与浅滩。
5. 通过最后一道浮标后返回港口，计时结束。

帆面效率会根据船身与风向的夹角变化。屏幕下方的帆面指示器越接近有效区间，航行效率通常越高。

## 操作

| 操作 | 键盘 | 触屏按钮 |
| --- | --- | --- |
| 向左转舵 | `A` / `←` | 左转 |
| 向右转舵 | `D` / `→` | 右转 |
| 收帆 | `W` / `↑` | `−` |
| 放帆 | `S` / `↓` | `+` |
| 切换近景 / 远景镜头 | `C` | — |
| 开关海浪与风声 | `M` | 声音按钮 |
| 重新开始 | `R` | 完赛页“再次航行” |

最佳成绩保存在浏览器的 `localStorage` 中，刷新页面后仍会保留。

## 实现概览

### 实时海面

海面使用多层波形近似 Gerstner 海浪，并在顶点着色器中计算动态高度与法线。船体位置、俯仰、横滚和浮标姿态也会采样同一套海浪高度，使场景运动保持同步。

### 帆船运动

航行速度综合考虑以下因素：

- 船身朝向与风向的夹角
- 当前帆面角度
- 帆面效率
- 转舵造成的阻力
- 岛屿碰撞后的速度损失

帆船会随海面坡度起伏，并根据风压与航速产生横滚倾斜。

### 程序化场景

场景中的船体、帆面、岛屿、植被、灯塔、浮标和航迹均通过几何体与着色器实时生成，无需加载外部 3D 模型或贴图。

### 音效

海浪与风声由 Web Audio API 实时合成，并根据航速调整强度。浏览器要求用户交互后才能播放音频，因此音效会在开始航行或首次切换声音后启用。

## 开发与测试

检查 JavaScript 语法：

```powershell
npm run check
```

运行冒烟测试：

```powershell
npm test
```

冒烟测试会验证页面启动、倒计时、转向输入、完整浮标路线和完赛流程。

## 浏览器兼容性

游戏依赖 WebGL 2.0 与 ES Modules，建议使用较新的桌面或移动浏览器。若浏览器或显卡不支持 WebGL 2，页面会显示兼容性提示。

## 项目说明

本项目以单页、零依赖和小体积为目标，适合用于学习：

- 原生 WebGL 2 渲染管线
- 程序化 3D 几何与场景搭建
- 着色器中的海面波形与光照
- 简化帆船动力学
- Canvas HUD、小地图和响应式触屏交互
