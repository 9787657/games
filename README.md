# 蔚蓝航线 · AZURE RUN

一款不依赖第三方库的原生 WebGL 2 帆船竞速游戏。海面、天空、岛屿、帆船、浮标和全部界面材质均为程序化生成，可直接离线运行。

## 启动

```powershell
npm start
```

浏览器打开 `http://127.0.0.1:4173`。

## 操作

- `A` / `D` 或左右方向键：转舵
- `W` / `S` 或上下方向键：调帆
- `C`：切换近景 / 远景追逐镜头
- `M`：开关海浪与风声
- 触屏设备会显示转向和调帆按钮

依次穿过 6 道浮标后返回港口。帆面效率会受到船身与风向夹角的影响，调整帆面可提高速度。

## 技术

- 原生 WebGL 2，零运行时依赖
- 顶点着色器 Gerstner 风格海浪与动态法线
- 程序化船体、帆面、岛屿、植被、 lighthouse 与浮标
- 实时淡入雾、风效、航迹泡沫、竞速计时与小地图
